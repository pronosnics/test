# PDB Hub Media 0.1.0 — 28 novembre 2026

Modulo separato; non sostituisce PDB Atlante 0.2.14 o PDB Hub 0.2.0. Consentiti soltanto gli otto ID hub 778, 8770–8776 e soltanto amministratori autenticati con upload_files e edit_post. Nessuna pubblicazione o modifica delle relazioni botaniche. La directory temporanea è privata e fuori dal percorso web; sessioni di un'ora, controllo proprietario, lock, SHA-256, MIME e dimensioni. Limite 8 MiB/file, blocchi max 48 KiB; procedura collaudata lato client da 24.000 byte raw (32.000 caratteri base64), offset sequenziale. Nessuna sovrascrittura di media precedente; replace_featured esplicito quando presente. Se l'import restituisce imported_not_assigned, non ripetere finish: controllare l'ID e il motivo.

Ability: pdbhub/media-start, pdbhub/media-chunk, pdbhub/media-finish, pdbhub/media-abort. Dopo installazione, scoprire le ability, leggere #8771, provare start/abort, poi effettuare trasferimento reale della copertina cereali e legumi. Verificare checksum e ID, ALT, didascalia, stato draft e slug; verificare assenza di regressioni su una monografia. Non dichiarare riuscito prima del collaudo reale. Se non funziona, disattivare solo questo modulo. Non consumare il reset WPVibe.
